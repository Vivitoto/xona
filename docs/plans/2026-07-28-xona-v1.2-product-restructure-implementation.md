# Xona v1.2 Product Restructure Implementation Plan

> **For implementer:** Use TDD throughout. Write failing tests first where behavior changes are user-visible. Watch them fail. Then implement the smallest passing change. Do not push, tag, publish Docker images, or remove unrelated files.

**Goal:** Restructure Xona around two core features — `本地元数据生成` and `XChina 元数据搜索` — while removing automatic monitoring/confidence concepts from the visible product and upgrading the UI to a flat premium tech theme with light/dark mode.

**Architecture:** Keep backend compatibility initially, but replace the frontend information architecture and add a job-independent XChina API surface. Reuse the existing local metadata backend for local generation, extracting frontend components for single and batch modes. Theme mode is an app-level provider using CSS tokens and localStorage.

**Tech Stack:** FastAPI + SQLAlchemy backend, React + TypeScript + Vite frontend, Vitest/Testing Library/Playwright tests, existing `apiFetch`, existing `DirectoryPicker`/storage-root APIs, Docker release gate.

## Phase 2 — Independent XChina metadata search

### Task 4: Add job-independent XChina API schemas and endpoints

**Files:**
- Create: `backend/app/schemas/xchina_search.py`
- Create: `backend/app/api/xchina_search.py`
- Modify: `backend/app/main.py`
- Test: `tests/backend/api/test_xchina_search_api.py`

**Behavior:**
- Add endpoints:
  - `POST /api/xchina/search`
  - `POST /api/xchina/detail`
  - `GET /api/xchina/image-proxy?url=...`
- Search request accepts `query`, optional `normalized_query`, optional settings overrides if already supported safely.
- Detail request accepts direct `source_url` and optional embedded detail payload for tests.
- Endpoints reuse the same XChina settings resolution/image proxy safety rules as manual organizer.
- Search/detail do not require a local job id, media item, source path, or confidence threshold.

**Test first:**
- Backend test should install a fake adapter in app state, call `/api/xchina/search` without a job id, and assert candidates return.
- Backend test should call `/api/xchina/detail` with direct URL and assert metadata returns.

**Verify:**
